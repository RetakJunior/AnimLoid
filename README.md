# AnimLoid
Türkçe ve İngilizce kaynaklardan terminal üzerinden anime izleyip indirin. MPV, Aria2, Discord RPC ve MAL/AniList entegrasyonu dahil. İzleme geçmişinizi takip edin, kaldığınız yerden devam edin. weeb-cli'den ilham alınarak yapılmıştır. (Eger isterseniz .appImage dosyasini kullanarak bir uygulama seklindede kullana bilirsiniz assets kisminda var).
